# 🧃 ML Juice POS — Aplikasi Kasir Minuman Segar & Sehat

Aplikasi kasir Point of Sale (POS) Android modern khusus kedai jus buah, smoothies, dan minuman segar **ML Juice**. Dibangun dengan arsitektur **Offline-First** (Room Database) dan tersinkronisasi otomatis dengan **Google Cloud Firebase (Free Tier)**.

## ✨ Fitur-Fitur Utama

* 🍹 **Katalog Menu Lengkap & Modifikasi Rasa**:
  - Pilihan Ukuran: *Reguler (16oz)*, *Large (22oz)*, *Jumbo (32oz)*
  - Takaran Es: *Normal Ice*, *Sedikit Es*, *Tanpa Es*
  - Takaran Gula: *Normal (100%)*, *Sedang (50%)*, *Tanpa Gula*
  - Topping Tambahan: *Brown Sugar Boba*, *Rainbow Jelly*, *Chia Seed*
* 💰 **Kalkulator Kasir Cepat**:
  - Tombol instan uang tunai (*Uang Pas, 20.000, 50.000, 100.000*)
  - Hitung kembalian instan otomatis
  - Dukungan pembayaran *Tunai*, *QRIS*, dan *Transfer*
* 🖨️ **Cetak Struk Bluetooth Thermal ESC/POS (58mm / 80mm)**:
  - Cetak struk pelanggan lengkap nomor antrian
  - Cetak tiket dapur/barista otomatis
* 🍳 **Kitchen Display System (KDS)**:
  - Layar antrian pembuatan minuman barista secara real-time
  - Status pesanan: *Menunggu ➔ Sedang Dibuat ➔ Siap Diambil ➔ Selesai*
* 📊 **Laporan & Rekap Penjualan**:
  - Total omset harian & jumlah transaksi
  - Rincian penerimaan tunai vs non-tunai
  - Peringkat 10 menu paling laris (Best Sellers)
  - Fitur kirim ringkasan laporan ke WhatsApp
* ⏰ **Shift Kasir & Cash Drawer**:
  - Catat modal kasir awal buka toko
  - Rekonsiliasi dan hitung selisih kas saat tutup toko
* 🔐 **Autentikasi & Akun**:
  - Masuk cepat dengan **Akun Google (Google Sign-In)**
  - Daftar & Masuk dengan Email / Password
  - Mode Kasir Tamu (Offline Mode instan tanpa login)
  - Menu profil akun dengan fitur **Ganti Kata Sandi**

## 🛠️ Cara Memasang di HP / Tablet Android

1. Unduh file **[MLJuice-POS.apk](https://github.com/mandelaxx/mljuice-pos/releases/download/v1.0.0/MLJuice-POS.apk)** di atas.
2. Buka file hasil unduhan di HP Anda.
3. Jika muncul konfirmasi *"Izinkan instalasi dari sumber ini"*, klik **Izinkan / Allow**.
4. Buka aplikasi **ML Juice POS** dan aplikasi siap digunakan bertransaksi! 🧃
